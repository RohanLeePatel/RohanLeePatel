I built the Python service behind it.<br>I'm looking to collaborate on Python projects that do real work: APIs, data tools, anything where the decisions can be inspected.<br>I'm looking for help with taking my recommendation engine from hand-tuned weights to something learned, without losing the explanations.<br>I'm currently learning machine learning the maths as much as the libraries.<br>Fun fact: Roamio's engine is deliberately *not* machine learning.
